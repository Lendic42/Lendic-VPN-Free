# Lendic VPN Free

Простой парсер бесплатных VPN-серверов. Проверяет доступность с домашнего компьютера: сначала TCP, затем HTTPS-запросы через VPN. Подписка обновляется примерно каждые **7 минут**, пока компьютер включён и пользователь вошёл в Windows.

**[Открыть подписку →](https://raw.githubusercontent.com/Lendic42/Lendic-VPN-Free/main/subscription.txt)** · Скопируйте адрес ниже и добавьте его в Happ или другой клиент: «Добавить подписку» → «Из буфера обмена».

```text
https://raw.githubusercontent.com/Lendic42/Lendic-VPN-Free/main/subscription.txt
```

Или отсканируйте QR-код сканером подписок в VPN-клиенте:

<p align="center"><a href="https://raw.githubusercontent.com/Lendic42/Lendic-VPN-Free/main/subscription.txt"><img src="assets/subscription-qr.png" alt="QR-код VPN-подписки Lendic VPN Free" width="460"></a></p>

В начале — до **10 ⚫**, затем до **10 ⚪**. В каждой группе серверы отсортированы по времени ответа HTTPS; повторные варианты одного адреса и порта убираются. Если рабочих узлов меньше, список будет короче. Страна взята из исходной подписки.

Источник: [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia). Это бесплатные сторонние серверы: доступность зависит от сети и может меняться. Если компьютер выключен или проверки полностью не удались, остаётся последняя опубликованная версия.
